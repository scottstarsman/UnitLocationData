# Bundled outline geography

`europe.geojson` is a subset of Natural Earth 1:50m Admin 0 Countries, downloaded November 1, 2026, with properties reduced to the country name. It retains the source geometry for 28 selected European country features. It is a modern cartographic reference, not a WWII boundary dataset.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson

Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/

The app uses it for an offline outline basemap; the normal online basemap comes from OpenFreeMap.
