# Responses to review findings

Each finding that comes back from an outside review is recorded here with the decision and the reason, using the format in [findings_template.md](findings_template.md), "For us: how a finding is handled". The findings are checked against the sources first; a finding is accepted, accepted in part, declined, deferred, marked known or answered with a request for information, and the reason is written down. Nothing here yet: no outside review of the current data has come back.

Ids look like `R1-F-001` (review number, then the reviewer's own id). Accepted changes are cited by finding id in `docs/changelog.md` and in the commit message.
